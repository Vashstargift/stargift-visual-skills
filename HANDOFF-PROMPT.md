# Передаточный промпт (скопируй другому Клоду целиком)

Ты подхватываешь два готовых визуальных навыка StarGift (stargift.ru): оформление фото
экспонатов по эталонам и премиум-презентации. Всё лежит в приватном репо
`github.com/Vashstargift/stargift-visual-skills`.

Сделай в таком порядке:

1. Склонируй репо (доступ: аккаунт Vashstargift; если git-доступа нет — попроси у меня
   токен или добавь свой deploy-key в настройках репо).
2. Прочитай ПОЛНОСТЬЮ `README.md` — там архитектура, таблица 13 утверждённых стилей рам,
   железные правила и все известные грабли с решениями. Потом `premium-deck/SKILL.md`
   (рабочая инструкция по презентациям) и `mcp-integration.md` (как навыки вызываются ботом).
3. Адаптируй окружение (чек-лист в README, раздел «Зависимости и адаптация»):
   - замени жёсткие пути `/Users/docbrown/...` на свои (перечислены в README);
   - поставь Python-зависимости: Pillow, python-pptx, playwright или системный Chrome;
   - подключи Higgsfield MCP (генерация, модель nano_banana_2) и Telegram-токен в .env;
   - установи шрифты (в репо их НЕТ по лицензии): Proxima Nova для гравировки шильдов
     (пути в `framing/framing_tool.py: _FONT_FILES`), Prata/Golos Text для презентаций.
     Гоча: в ходовых наборах Proxima Nova регуляр = отдельное семейство «Proxima Nova Rg»;
   - для .key-конвертации нужен macOS с Keynote (иначе отдавай .pptx).
4. Прогони смоук-тесты:
   - оформление: `frame_exhibit_photo(<фото>, "TEST NAME", "", "brand")` — рама, прямоугольный
     золотой шильд с именем, фото целиком;
   - packshot: то же с `"packshot-black"` — предмет на чёрном, без рамы и шильда;
   - композит: `frame_cinema_composite(<фото1>, <фото2>, "TEST")` — мгновенно, по шаблону;
   - презентация: `presentation_v2.make_and_send(...)` на 2-3 лотах — придёт PDF + редактируемая.
5. Сверь результат с эталонами: `framing/refs/*` (реальные оформления с витрины) и
   `premium-deck/etalon-legendy-kino-v2-final.pdf` (утверждённая дека).

Правила, которые НЕ обсуждаются (детали в README):
- сам предмет и автографы не перерисовываются никогда; фото целиком, без обрезки краёв;
- рамы только из `framing_styles.json` (цвет паспарту/рамы варьировать можно, тип — нет);
- шильд строго прямоугольный, с именем; золотой, для серебристых рам — серебряный;
- кино-композиты только шаблонной вклейкой, не генерацией;
- в презентациях: два рендера (PDF и pptx) — любые правки вёрстки вносить в оба; текст
  режется только по границе предложения; фото слайда одного размера на общей линии;
  без счётчиков экспонатов и итоговых сумм; описания не пересказывают название лота.

Если что-то в правилах мешает или выглядит ошибкой — не правь молча, опиши проблему
и спроси Вашика.
